# AGENTS.md

Dimascord REST API на NestJS и TypeScript.

## Применение инструкций

- Перед изменением файлов прочитай применимые вложенные `AGENTS.md`.
- При изменении кода или конфигурации прочитай
  [стандарты разработки](docs/development/standards.md).
- При изменении поведения или тестов прочитай
  [стандарты тестирования](docs/development/testing.md). TDD обязателен:
  тесты пишутся перед реализацией.
- При выполнении задачи с изменениями в репозитории прочитай
  [порядок работы и ревью](docs/development/workflow.md).
- При выборе возможностей NestJS, добавлении зависимостей или изменении
  интеграции с фреймворком прочитай [справку NestJS](docs/development/nestjs.md)
  и проверь актуальную документацию для используемой версии.

## Границы задачи

- Сохраняй существующие пользовательские изменения.
- Код соседних модулей меняй только для связи модулей друг с другом.
  Улучшения кода выноси в отдельные задачи.
- Согласованные требования к архитектуре, API, данным и проверкам находятся
  в тематических документах выше; используй их как источник стандартов.
