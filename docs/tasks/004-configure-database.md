# 004 — Настроить подключение TypeORM и конфигурацию окружения

Родитель: [003](003-initialize-database.md), раздел «Подключение и конфигурация».
Статус: реализовано, подготовка к ревью. Зависимостей от других дочерних задач нет.

Добавить совместимые зависимости, DatabaseModule, общую валидируемую
конфигурацию приложения и CLI DataSource, обнаружение файлов текущего формата
в src/dist. Отключить synchronize и migrationsRun. Добавить .env.example
и локальный игнорируемый .env.

Проверки: TDD для обязательных значений, портов, защиты пароля и приоритета
переменных процесса; unit-тесты, сборка, подключение приложения к тестовой БД.

## Согласованные границы тестирования

Публичная конфигурация проверяет ошибки до подключения и параметры TypeORM;
интеграция DataSource проверяет PostgreSQL и миграции; HTTP проверяет GET /.
Эти границы следуют требованиям родительской задачи.

Результат: общий загрузчик env, DatabaseModule и CLI DataSource добавлены;
unit-тесты конфигурации, проверка типов, сборка и подключения на хосте/в Docker
прошли. Производственная схема при старте не изменяется.
