# 006 — Добавить команды миграций для исходников и dist

Родитель: [003](003-initialize-database.md), раздел «Миграции».
Статус: реализовано, подготовка к ревью. Зависимость: [004](004-configure-database.md).

Добавить migration:create/generate/run/revert/show и :prod для последних трёх.
Использовать общий DataSource без фиктивных производственных миграций.
Описать команды на хосте и в контейнерах, имя и путь миграции.

Проверки: создание миграции, генерация без изменений, run/show/revert на пустой
производственной схеме из TS и dist; dist CLI с одними runtime-зависимостями.

Результат: все команды проверены. Шаблон создан вне репозитория; generate
без сущностей сообщил об отсутствии изменений (ожидаемый exit 1).
run/show/revert проходят из TS и в production-контейнере без ts-node.
