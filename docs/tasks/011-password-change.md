# 011 — Смена пароля из аккаунта

Тип: отложенная продуктовая задача. Статус: реализацию не начинать.
Связана с задачей 008 «Регистрация, вход и управление сессиями пользователя».
Зависит от базовых пользователей и сессий задачи 008.

## Цель

Авторизованный пользователь может сменить свой пароль из аккаунта.
В первую версию регистрации и входа эта возможность не входит.

## Уточнить до реализации

- Подтверждать ли действие текущим паролем; нужна ли дополнительная
  повторная аутентификация.
- Завершать ли остальные сессии, сохранять ли текущую и менять ли её секрет.
- Разрешать ли новый пароль, совпадающий с текущим.
- Как пользователь, зарегистрированный только через Google, задаёт первый
  локальный пароль. Не считать отсутствие пароля пустым паролем.
- Ограничения частоты и уведомление владельца по email.

## Ожидаемый результат и проверка

После согласования проверки личности пользователь устанавливает новый пароль.
Новый пароль соответствует требованиям задачи 008: 8–128 символов,
без требований к составу и без нормализации или обрезки. Новый пароль
подходит для входа, прежний больше не подходит.

Критерии приёмки должны проверить успешную смену, неверное подтверждение,
недействующую сессию, невалидный новый пароль, конкурентные запросы,
сбои зависимостей и согласованное поведение остальных сессий.
Доступ к смене чужого пароля исключён. Пароли и их хеши не возвращаются
в ответах и не включаются в диагностику.

Перед реализацией согласовать продуктовые требования и технический подход,
затем выделить дочерние технические задачи по workflow проекта.
